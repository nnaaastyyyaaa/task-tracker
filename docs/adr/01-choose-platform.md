# Вибір платформи для серверу: Node.js

## Контекст і проблема

Потрібно реалізувати вебзастосунок task-tracker із HTTP API, ролями користувачів і канбан-дошкою. Треба обрати платформу для серверної частини.

## Чинники рішення

- Швидкий старт і невелика кількість шаблонного коду
- Знайомство автора з мовою
- Багата екосистема пакетів і інструментів для тестування та перевірки якості
- Проста локальна розробка без важкого середовища

## Розглянуті варіанти

- Node.js
- Python

## Результат рішення

Обрано Node.js, тому що він дає швидкий старт, знайомий автору стек JavaScript і зручні інструменти для тестів та перевірки коду.

### Наслідки

- Плюс: одна мова та єдиний менеджер пакетів (`npm`) для коду, тестів і скриптів перевірок.
- Мінус: відсутня статична типізація, тому частину помилок мають ловити тести та лінтер.

## Плюси і мінуси варіантів

### Node.js

- Плюс: швидкий старт, велика екосистема npm, простий запуск (`npm start`).
- Мінус: без статичної типізації.

### Python

- Плюс: лаконічний синтаксис, зрілі фреймворки.
- Мінус: інший стек для інструментів і скриптів проєкту.
