# Task-tracker

Застосунок на **Node.js** для керування задачами в командах — спрощений аналог Jira. Team lead створює проєкти та призначає задачі, а учасники команди працюють із задачами на канбан-дошці.

## Ролі

| Роль            | Можливості                                                                                    |
| --------------- | --------------------------------------------------------------------------------------------- |
| **Team lead**   | Створює проєкти, додає учасників до проєкту, створює задачі та призначає їх учасникам команди |
| **Team member** | Бачить проєкти, до яких його додали, переглядає дошку проєкту, фільтрує задачі                |

## Функціонал

- Реєстрація та автентифікація користувачів
- Створення проєктів (team lead)
- Додавання учасників до проєкту (team lead)
- Створення задач і призначення їх виконавцям (team lead)
- Канбан-дошка проєкту зі стовпцями за статусами
- Перегляд задач усієї команди або лише власних (фільтр)
- Зміна статусу задачі

## Задача

Кожна задача містить:

| Поле          | Опис                                   |
| ------------- | -------------------------------------- |
| `title`       | Назва задачі                           |
| `description` | Опис                                   |
| `assignee`    | Ім'я учасника, якому призначено задачу |
| `priority`    | Пріоритет: `LOW` / `MEDIUM` / `HIGH`   |
| `status`      | Поточний статус на дошці               |

## Статуси та пріоритети

**Статуси (стовпці дошки):**

```
TODO  →  IN_PROGRESS  →  REVIEW  →  DONE
```

**Пріоритети:** `LOW`, `MEDIUM`, `HIGH`

## Сторінки застосунку

1. **Головна** — список проєктів, до яких додано поточного користувача. Для team lead також доступне створення нового проєкту.
2. **Сторінка проєкту** — дошка з чотирма стовпцями (TODO / IN_PROGRESS / REVIEW / DONE). Перемикач: «Усі учасники» / «Тільки мої задачі».
